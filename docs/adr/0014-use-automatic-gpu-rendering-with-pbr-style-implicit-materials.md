# Use automatic GPU rendering with PBR-style implicit materials

Interactive implicit surfaces use the active VTK OpenGL GPU volume mapper and report the actual OpenGL renderer. Software rasterizers such as llvmpipe or GDI Generic are treated as an explicit degradation rather than being labelled as GPU rendering.

Polygon meshes continue to use native VTK PBR interpolation. Implicit zero isosurfaces remain GPU ray-cast volumes to preserve the no-display-mesh architecture; their metallic and roughness controls are mapped to calibrated ambient, diffuse, specular, and highlight-width coefficients. Quality presets also control sample distance, interpolation, jittering, global illumination reach, scattering, anti-aliasing, SSAO, and mesh shadows.

FXAA is retained for implicit views at every anti-aliased quality level. VTK's SSAA render pass omits embedded volume props and would make the implicit result disappear. High and Ultra quality combine denser ray sampling with evaluator-backed display-field rebuilds at respectively 75% and 50% of the normal spacing; reducing ray step size alone cannot recover geometry or normals absent from a coarse three-dimensional scalar grid.

Lighting uses a restrained model-centred studio rig with one dominant key and deliberately weak fill, rim, and low-fill lights. Strong opposing lights produced visible Lambertian terminator bands on smooth GPU implicit surfaces and repeated point highlights on PBR meshes. A compact procedural equirectangular studio environment is therefore used for mesh image-based lighting without being shown as the viewport background. This preserves dark-surface information while both mesh and implicit paths retain one coherent CAD material response.

The default viewport uses a subtle near-white CAD background with the ground plane and ground grid disabled; pure white and dark alternatives remain available. High quality is the default. Its smooth PBR path omits VTK's visibly noisy SSAO kernel, while Ultra retains SSAO and mesh shadows for deliberate high-cost inspection. The model is framed with an orthographic camera, and wheel zoom changes `parallel_scale` so close inspection can continue without the perspective dolly reaching a clipping limit. World axes use the conventional mapping X=red, Y=green, and Z=blue; the standard front/back/left/right/top/bottom views are defined from the corresponding world directions.

Implicit bodies are rendered from bounded sampled scalar-field caches. The cache resolution is independent from the user-selected generation voxel size: when no explicit display spacing is supplied, it is recommended from the physical cell and wall sampling constraints and then adjusted to the display-memory budget. This keeps a deliberately coarse generation configuration from producing a visually under-sampled interactive preview.

High and Ultra display fields are rebuilt asynchronously from the authoritative implicit evaluator rather than interpolated from the normal display array. They use a Design-document-local cache keyed by quality, source-field identity, and effective per-layer budget. The budget accounts for the resident source field and CPU/GPU copies, old quality variants are pruned, and a budget-limited rebuild is reported instead of silently claiming full requested fidelity.
