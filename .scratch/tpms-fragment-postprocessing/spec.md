# TPMS 悬空小结构后处理

## 目标

针对隐式场采样和 Marching Cubes 过程中产生的孤立悬空小结构，提供可审计、物理尺度约束的后处理，同时保留真实的多连通晶格结构并允许导出警告结果。

## 约束

- 负值表示材料，后处理优先作用于隐式场而不是三角面片。
- 仅删除明确满足相对体积和物理尺寸条件的内部小分量。
- 接触采样网格边界的分量不自动删除。
- 超过阈值的多连通分量保留，并在质量检查中报告。
- 分块 Marching Cubes 不构造完整场时，继续使用网格层面的数值碎片清理。

## 验收标准

1. 人工构造的孤立小场分量在 Marching Cubes 前被移除。
2. 边界接触分量和工程尺度独立分量被保留。
3. `resources/鞋底/1.stl` 的 G/D 回归结果保持水密、法向一致、连通量为 1。
4. 既有非 CUDA 回归测试全部通过。
